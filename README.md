N-Queens Problem ♛
Implementation of the N-Queens Problem using the Backtracking algorithm in C++.

📖 Description
The N-Queens problem involves placing N queens on an N×N chessboard such that no two queens attack each other.

The solution uses Backtracking to explore valid positions while eliminating invalid configurations efficiently.

✨ Features
Backtracking approach
Validity checking for queen placement
Displays one or more valid solutions
Demonstrates recursive problem solving

🛠️ Technologies Used
C++
Backtracking Algorithm

📊 Complexity
Time Complexity: O(N!)
Space Complexity: O(N²)

▶️ Compilation & Execution
g++ n_queens.cpp -o n_queens
./n_queens
